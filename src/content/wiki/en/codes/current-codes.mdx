## Why does an empty verified list still help?

Players searching for codes need a clear current answer, including when the answer is “none verified.” Removing the page would leave older search results and copied lists without a maintained correction. Filling it with plausible-looking strings would be worse: a fake code wastes time and can direct players toward unsafe websites.

The empty list is therefore an editorial result. It records what was checked, separates active and expired history, and explains what evidence would change the answer. The check date matters because it limits the claim to a specific review rather than promising that the game can never add a redemption system.

## What does not qualify as a verified code?

- A string shown only in a search snippet or copied article.
- A creator video with no matching developer-controlled announcement.
- Text another player says worked without a visible redemption screen and reward.
- A Roblox chat command, display name, group code, or private-server link.
- A survey, download, browser extension, or login form that promises a reward.
- A code for a different Roblox experience with a similar title.

Popularity is not verification. Ten sites can repeat the same unsupported string from one source. Independent confirmation requires a current input path and an observable result in the correct experience.

## How can you check the experience identity?

Use the official Roblox link above and compare the experience title and creator shown there. Do not rely only on a thumbnail, because copied pages can reuse images. If a source links somewhere else, inspect the destination before signing in or installing anything.

The official game page can prove which experience is being discussed, but it does not prove a code unless the developer publishes one there or through another controlled channel. Keep identity evidence and code evidence separate.

## What happens when a code feature appears?

This page should be updated in a fixed order. First record the visible menu path. Then preserve the exact code spelling and attributable source. Test the result on an eligible account, record the response and reward, and add the check date. If a second account or independent observer confirms the same result, note that without exposing account information.

An expired entry needs evidence too. A generic error may mean the code is expired, mistyped, already redeemed, region-limited, or temporarily unavailable. The status should remain unresolved until the response or official source supports “expired.”

## How often should you recheck?

Recheck after a developer announcement, a visible UI change, or a game update that mentions gifts, rewards, settings, or codes. Reopening the same unchanged interface every hour does not create new evidence. A dated review after a meaningful trigger is more useful than a falsely “live” timestamp generated on every page load.

When nothing has changed, update notes should say that the prior conclusion remains in place only if a real check occurred. Do not change `lastModified` merely to look fresh.

## How can readers report a possible code safely?

Use the [contact page](/contact) and include the candidate string, developer-controlled source URL, visible redemption path, exact response, and date checked. Remove usernames and other personal information from screenshots. Never include a password, session cookie, recovery code, payment detail, or private message unrelated to the claim.

Submissions do not appear automatically. A maintainer reviews them under the [source policy](/wiki/source-policy) before changing this list. Until then, the candidate remains unverified.

## What should you do when another site lists a new code?

Treat the listing as a lead, not confirmation. First make sure it refers to the same Roblox experience, because similarly named games can have different developers and reward systems. Look for a developer-controlled announcement and a visible redemption interface in the live game. If there is no place to enter the string, repeatedly pasting it into chat or unrelated fields cannot establish that it is valid.

Avoid racing a copied list into publication. A short delay used to verify the source, exact capitalization, reward, and result protects readers from fake-code loops. If the code later becomes verifiable, this page can record the check date and move it between active and expired states when the live response changes.
