## Where do you enter codes?

There is currently no verified place to enter a promotional code in Steal an Egg. Do not paste unverified strings into chat, browser forms, or third-party websites.

## How to verify a future code system

When an update claims to add codes, check in this order:

1. Open the current game from its [official Roblox page](https://www.roblox.com/games/107778070777162/Steal-An-Egg).
2. Look for a clearly labeled Codes, Redeem, Gift, or Settings field.
3. Confirm that the developer or an in-game announcement published the string.
4. Record the exact reward and whether the code is account-limited.
5. Rejoin once if the interface appears stale, but never enter account credentials elsewhere.

<Callout type="danger" title="Account safety">A code website never needs your Roblox password, cookie, recovery code, or browser extension.</Callout>

## What would a legitimate redemption path look like?

A legitimate path stays inside the official experience or another developer-controlled interface. It should have a clear label, accept the code as text, and return a result that explains success or failure. The exact location may change if the developer introduces the feature, so this guide will document the observed menu rather than inventing a sequence in advance.

An external article can help you discover an announcement, but it should not ask for control of your Roblox account. A normal promotional code is not a reason to install an extension, paste browser data, disable security features, or send a verification payment.

## How should you prepare before testing a future code?

1. Confirm that you opened the official experience linked above.
2. Read the developer source and preserve its publication date.
3. Copy the exact string, including punctuation and capitalization.
4. Record the account's relevant reward balance without exposing private details.
5. Enter the code once through the visible game field.
6. Record the response and any balance change.
7. If it fails, inspect the message before trying random variations.

This process distinguishes a working code from an already-redeemed or mistyped code. It also provides enough context for another editor to review the claim.

## What do common error messages mean?

The wording of a future interface must be read literally. “Invalid” may indicate a typo or an unsupported string. “Already redeemed” supports that the account used it before, but does not by itself prove the code remains active for new accounts. “Expired” is stronger status evidence when the game shows it directly. A network or generic error should be retested later rather than assigned a permanent status.

Do not report a code as working solely because the field accepted the text. Verify the reward named by the source and check that the relevant balance or inventory changed.

## How can you spot a copied fake-code page?

Warning signs include no current check date, no screenshot or description of the redemption field, strings that belong to another game, a long list of rewards without sources, and a button that redirects to a survey or download. A page can look polished and still copy unsupported data.

Check whether multiple articles use identical wording and the same typo. That pattern often reveals one repeated source rather than independent confirmation. The [current status page](/codes/current-codes) publishes an empty result when evidence is absent instead of rewarding copied claims with a larger table.

## Why should you avoid entering codes in chat?

Typing an ordinary string into public chat can expose it to other players without contacting a redemption system. Commands or links sent by strangers can also be unrelated to the game. Use only a clearly labeled developer-provided input. If the experience has no such field, stop there.

Never paste JavaScript, a browser-console command, a Roblox security cookie, or a one-time recovery value. Those are account-control mechanisms, not promo codes. Anyone asking for them to “activate” a reward is asking for information a legitimate code redemption does not need.

## How should you document a redemption test?

Record enough context to distinguish a real feature from a copied instruction. Include the official experience URL, device type, date, exact menu labels, the code as displayed by its source, and the complete success or error message. A screenshot may support the record, but crop account names, balances, chat, and notifications that are unrelated to the test. Never share cookies, recovery codes, or login details.

Test only through an interface the game itself presents. Do not install an extension, download a “code tool,” run a script, or visit a page that asks for a Roblox password. A legitimate wiki instruction should be reproducible with the normal game client and an official source. Once a working path exists, the guide should explain the steps in order and preserve common result meanings without promising that a time-limited reward will remain available.
