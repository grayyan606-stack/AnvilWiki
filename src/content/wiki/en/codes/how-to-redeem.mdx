## Where do you enter codes?

There is currently no verified place to enter a promotional code in Steal an Egg. Do not paste unverified strings into chat, browser forms, or third-party websites.

## How to verify a future code system

When an update claims to add codes, check in this order:

1. Open the current game from its [official Roblox page](https://www.roblox.com/games/107778070777162/Steal-An-Egg).
2. Look for a clearly labeled Codes, Redeem, Gift, or Settings field.
3. Confirm that the developer or an in-game announcement published the string.
4. Record the exact reward and whether the code is account-limited.
5. Rejoin once if the interface appears stale, but never enter account credentials elsewhere.

<Callout type="danger" title="Account safety">A code website never needs your Roblox password, cookie, recovery code, or browser extension.</Callout>

## Where verified codes will appear

The [current codes page](/codes/current-codes) is the canonical list. It separates active, expired, and unverified claims and includes a check date so old search results do not look current forever.
