## What does Cherry Blossom add?

- A new late-game biome beyond the earlier progression ceiling
- Cherry Blossom eggs and pets, including Crane
- The Sakura Incubator
- Great Bloom timed events
- Sakura Crystals
- Bloom and Spirit Bloom mutations

## How much speed do you need?

Recent guides report values from roughly **2.5B to 3.5B speed**. That range should not be collapsed into a fake exact answer. One source may describe entering the zone while another describes outrunning the guardian with an egg.

<Callout type="warn" title="Entry is not escape">Meeting a gate does not prove that you can carry a large egg home safely. Test the route with a conservative target and use the [readiness calculator](/tools/calculators#biome-calculator).</Callout>

## What should you do first?

Prioritize a Crane if you want to unlock the Sakura Incubator. Once unlocked, use Great Bloom event windows to collect crystals, then reserve Incubator attempts for eggs whose base value justifies the resource cost.

Continue with the [Sakura Incubator guide](/mutations/sakura-incubator) and [Cherry Blossom update notes](/updates/cherry-blossom-update).

## How should you prepare before entering?

First confirm the current gate in the live game and record whether it represents access or a recommendation. Measure treadmill gain in your own session, calculate the time to that value, and set a second target for route testing. The [speed calculator](/tools/speed-calculator) keeps those inputs visible.

Before carrying anything valuable, scout the path without an egg. Identify the nest, return turns, guardian movement, and locations where other players can block or compete. Time a full round trip, then repeat with an ordinary target. Use the slower normal result for planning.

## How should the reported speed range be used?

Treat 2.5B to 3.5B as a record of conflicting public advice from the cited review period. It is not a newly measured official gate. Inspect the live requirement and choose a personal buffer from observed route problems.

If you report a new value, state whether the game accepted entry, whether you completed one return, and whether repeated returns were comfortable. Those outcomes can produce different honest numbers. A current observation with a clear definition is more useful than copying the upper or lower endpoint.

## What is the Crane's role?

Current post-update guides identify Crane as the pet used to unlock the Sakura Incubator. Verify the live unlock prompt before submitting a pet, because this is a resource decision and the system can change. Record the prompt, pet state, and result without exposing account details.

Obtaining a Crane and obtaining a strong income pet are related but separate goals. If your priority is the Incubator, the unlock role can justify the target even when another pet offers more immediate income. State which goal you are ranking.

## How do you prepare for Great Bloom?

Reach the area before the expected window, learn a short crystal path, and observe the live event indicator. Record the actual start, end, and resource change. Do not publish a timer based on when an article page loaded or a single server that may already be partway through its cycle.

If the event timing differs from the current report, use the current server signal and preserve the observation as a possible conflict. One session helps your next visit; repeated aligned observations are needed before changing a public generalization.

## Which egg belongs in the Incubator?

Compare the egg or expected pet's value with the cost of the attempt. A mutation multiplies a base, so applying it to a stronger useful target can create more absolute income. However, rare resources and the uncertainty of the outcome may favor a more available test first.

Use current live values in the [Mutation Comparison](/tools/calculators#mutation-calculator). Label any hypothetical result as an example. The calculator cannot prove that the egg is eligible or that reported outcome chances remain current.

## How should you compare Cherry Blossom pets?

Start with visible card values under matched mutation and size conditions. Then account for the route and successful return rate. A high-end target that rarely reaches the base may contribute less progress during a normal session than a lower target on a reliable route.

The [All Pets Index](/pets/all-pets) exposes its incomplete coverage and evidence labels. Missing rows do not prove a pet is absent; they mean the full record has not yet been verified.

## What should a first successful visit accomplish?

Aim to leave with information even if the rare target does not appear. Confirm the gate, map a return path, identify the guardian cue, locate the Incubator, and observe any Great Bloom indicator. Record one full route time. Those facts improve the next attempt without requiring a lucky hatch.

Afterward, decide whether the bottleneck is speed, route reliability, the Crane unlock, crystals, or a suitable egg. Choose one next action instead of chasing every new system at once.

## What can make this guide stale?

A changed gate, biome order, guardian route, event schedule, Crane requirement, Incubator cost, outcome set, or pet roster would require review. An article modification date alone does not prove these mechanics were rechecked. Use the Evidence panel date and current live UI for decisions with substantial time or resource cost.

Report a correction via [Contact](/contact) with the exact page claim, date, visible condition, and de-identified evidence. Accepted changes are recorded in the [data corrections log](/updates/data-corrections).

When comparing a fresh observation with this guide, match the full sequence rather than one isolated number: access condition, route, event state, resource cost, eligible input, and visible result. A disagreement at one step should reopen that step only. This avoids discarding a still-useful route because a later reward changed, or treating an unchanged label as proof that the entire event works exactly as before.
