## Which identifiers should you include in a correction?

The official experience URL is the most useful starting point because another reader can open it directly. Copy that URL alongside the exact title and the date you checked it. If your evidence concerns a badge or purchasable item, include that item's official link separately; the experience link alone does not identify the specific award or product.

This page also preserves a universe ID from the earlier site reference. Do not treat a remembered number or a number copied from another wiki as fresh verification. The September check here confirmed what was visible on the linked experience page; it did not independently recheck that universe field. Keeping the limitation visible is preferable to silently presenting the entire table as newly validated.

A server session is another kind of context. Two players can be in the same experience but observe different crowding or event conditions. Your correction can describe the date and visible session state without publishing private access links or account information. That context helps explain a disagreement while keeping identity and gameplay evidence separate.

## Why can a correct-looking code still belong to the wrong game?

A short code string usually carries no obvious experience identity. The same word can appear in several games, and a search result can combine a current title with an old article. Before treating a code as evidence, check which experience its source actually demonstrates and when the result was recorded.

The same rule applies to badge names, pet names, and currency labels. Similar wording does not establish a shared reward system. If a guide lists a redemption menu that you cannot find, verify the game first before assuming your account is missing a feature. The [code redemption guide](/codes/how-to-redeem) explains how to record the live response without inventing an active reward.

Never use an external “verification” page that asks for account credentials as a substitute for the official game's interface. This wiki provides reference information and links; it does not redeem codes, grant pets, process purchases, or unlock account features on your behalf.

## What should you check when an older guide no longer matches?

Compare the source's date, experience URL, and visible interface before deciding that the guide is merely outdated. An identity mismatch and an update are different causes. The first means the source may never have applied to this game; the second means a formerly relevant source needs a new check.
