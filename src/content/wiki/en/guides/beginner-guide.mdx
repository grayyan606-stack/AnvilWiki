## What should you do first?

1. Learn one short Forest route and return several eggs without taking unnecessary fights.
2. Fill empty pet slots before optimizing small income differences.
3. Compare the actual income card after every hatch.
4. Spend early money on upgrades that increase repeatable income or movement progress.
5. Measure treadmill gain for 30–60 seconds and calculate a realistic target time.
6. Enter Lake only when you can return consistently, not merely cross the gate.

## Which early pets matter?

Any pet is useful while a slot is empty. Once the base is full, replace the weakest contribution first. Forest tracking starts with low-rate pets such as Chicken and Dog, then moves through Bird, Owl, Raccoon, Fox, and higher-rarity targets.

<Callout type="tip" title="Upgrade by total gain">Replacing a $2/s pet with $8/s adds $6/s. Replacing an empty slot adds the full new rate. Early capacity can therefore beat a small rarity chase.</Callout>

## When should you train speed?

Train when the next reliable route requires it. Avoid sinking all income into a distant biome while the current base still has easy slot improvements. Use the [Speed Goal Calculator](/tools/calculators#speed-calculator) and [Biome Readiness Checker](/tools/calculators#biome-calculator).

## How should the first hour be divided?

Think in checkpoints instead of a strict minute-by-minute script. First prove that you can take an ordinary egg and complete the return. Next, fill productive space at the base. Then compare live pet cards and replace the weakest useful contribution. Only after the basic loop is stable should you commit a long block to speed training or a difficult zone.

This order adapts to server conditions. A quiet server may make early routes easy; a crowded one may make observation and short safe returns more valuable. The goal is not to copy another player's timestamp. It is to leave the first session with a loop you can repeat and measurements you understand.

## What should you record after each hatch?

Write the pet name, visible biome or source, rarity label, displayed income, visible mutation, size state, and check date. Use the displayed contribution when comparing immediate slot changes. Do not assume that rarity alone determines income, and do not apply a mutation multiplier again if the card already includes it.

When a slot is empty, compare the new pet with zero. When every slot is occupied, compare it with the weakest current contribution. This small distinction prevents beginners from discarding a useful pet simply because a rarer name appeared.

## Which upgrades should come first?

Prefer an upgrade that removes a current bottleneck. Capacity matters when good pets are waiting without a slot. Movement matters when every useful next route fails on speed. Income improvements matter when earning is too slow for the next practical purchase. A purchase with no clear effect on the next repeatable loop can wait.

Before spending, answer three questions: what changes immediately, how will you measure the change, and what useful option are you delaying? If the game description or purchase screen does not clearly state an effect, avoid inventing one. The [gamepasses guide](/wiki/gamepasses) explains how to evaluate paid options without promising undocumented benefits.

## How do you practice without risking the best egg?

Use ordinary targets to learn the route. Time the full trip out and back, observe a full guardian cycle, and choose a visible launch cue. Repeat until you can explain why a run succeeded. Then introduce one harder condition, such as a larger target or a narrower timing window.

If other players crowd the route, switch targets or train instead of forcing the same attempt. Early progression rewards successful repetition more reliably than dramatic failures. The [safe stealing guide](/guides/how-to-steal-eggs) gives a full route worksheet.

## When are you ready for the next biome?

Treat the visible gate as the start of testing. A first entry proves access; it does not prove a safe return while carrying. Add a personal margin based on turns, guardian pressure, server delay, and mistakes you observe. Test with a replaceable egg before committing a rare target.

Record three outcomes separately: entered, picked up, and returned. If entry succeeds but returns fail, more practice or margin may be needed. If the route succeeds repeatedly but rewards no longer improve the base, progressing becomes more attractive.

## How should you use calculators as a beginner?

Calculators turn your inputs into comparisons; they do not discover hidden game rules. Use the [income calculator](/tools/income-calculator) to compare the current weakest slot with a candidate. Use the [speed calculator](/tools/speed-calculator) after measuring a real treadmill sample. Use the run planner only after timing a complete route.

Label hypothetical inputs as examples. A clean calculation from invented numbers remains hypothetical and should never become a pet database entry or a claimed biome requirement.

## What mistakes slow early progress?

- Chasing a contested rare target before learning a safe return.
- Replacing a strong mutated pet based only on another pet's base rarity.
- Training toward a distant headline number without testing the next useful route.
- Buying an option whose current effect was never checked in the live interface.
- Copying an old code list even though no redemption field is available.
- Treating one unusually fast run as a normal route time.

Each mistake hides the real bottleneck. Return to the last repeatable step, measure one variable, and make the smallest useful change.

## What should a successful first-session note contain?

Keep the current weakest pet contribution, best reliable route, typical return time, current speed, measured gain rate, next visible requirement, and one next action. Add the date because live games change. This note gives the next session a starting point and makes future advice testable.
