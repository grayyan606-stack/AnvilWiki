## What was added?

- Cherry Blossom biome
- New Cherry Blossom pets, including Crane
- Sakura Incubator
- Great Bloom event
- Sakura Crystals
- Bloom mutation at a tracked 1.5×
- Spirit Bloom mutation at a tracked 3×

## Why does this update affect old guides?

Before the update, many lists ended at Cosmic and described nine biomes. Search results may still surface those pages, which can also produce smaller pet totals. Post-update content must state whether Cherry Blossom is included.

## What should players do next?

Check the [Cherry Blossom biome guide](/biomes/cherry-blossom), then prepare a Crane for the [Sakura Incubator](/mutations/sakura-incubator). Use a multi-billion-speed safety target based on the current live gate rather than copying one static number.

Sources: [Timesaver update summary](https://timesaver.gg/blog/steal-an-egg-cherry-blossom-update) and [Sakura Incubator guide](https://beebom.com/steal-an-egg-sakura-incubator-guide/).

## Which claims are stable and which need a fresh check?

The named additions above are the stable scope of this summary because multiple post-update sources describe them together. Exact access speed, event timing, outcome chances, pet totals, and earnings are more fragile. Those values can depend on what a source measured, when it measured it, and whether it describes entry or safe play.

This distinction matters when reading old guides. A page can correctly describe the earlier nine-biome progression while being incomplete for the current game. It does not become fraudulent simply because the game changed, but it should not be used as a current total without a version boundary.

## How should a returning player audit an old plan?

Start with the last biome and target in the old plan. Confirm that the old route still exists and inspect the live progression interface for a new requirement. Then review the weakest base slot, current speed, and any saved mutation assumptions. Do not discard the whole plan automatically; mark which inputs remain visible and which now need replacement.

Use the [All Biomes guide](/biomes/all-biomes) for the revised order and the [All Pets Index](/pets/all-pets) for the conservative tracked subset. If an older pet remains valuable in your live base, a newer zone does not make it useless.

## What is the new progression chain?

The reported system forms a sequence rather than a collection of unrelated features:

1. Reach the Cherry Blossom area under current live conditions.
2. Learn a return route with enough margin for an egg.
3. Obtain and hatch the Crane required by current Incubator reporting.
4. Use the Crane at the Sakura Incubator unlock.
5. Observe a Great Bloom window and collect Sakura Crystals.
6. Choose an egg whose value justifies an Incubator attempt.
7. Verify the resulting mutation on the live pet card.

Each step should be confirmed before resources are committed. A guide describing the last step cannot prove that your account has completed the unlock requirements.

## How should you prepare for Great Bloom?

Reach the area before a reported event window rather than spending the active period in transit. Identify the resource collection path during a low-pressure visit and decide what you will do if the event timing differs from an article. Current guides may report a cycle, but the live interface is the best source for your session.

Record the observed start, end, and crystal change separately. One observation helps plan the next visit; it should not be promoted into a permanent global schedule without repeated checks.

## How does the update change pet comparison?

New high-end pets expand the target set, but final contribution still depends on the visible pet value, mutation, size, and copies. Compare a candidate with the slot it would replace. The candidate's whole income is not the upgrade; only the difference is.

Use the [income calculator](/tools/income-calculator) with current card values. If a new pet requires a much riskier route or an Incubator investment, include that acquisition time in the decision instead of ranking only the headline base rate.

## What should editors revise after this update?

Pages that claim a permanent biome count, pet count, endgame ceiling, top-pet list, or mutation list need a scope note and check date. Internal links should connect the update, biome, Incubator, mutation, and pet pages so a reader can see where each fact is explained. Search descriptions should not say “all” if the body only covers the pre-update set.

Corrections belong in the [public data corrections log](/updates/data-corrections). A change to prose should update `lastModified`, while a fresh game claim also needs a new evidence check date. Those dates answer different questions.

## What remains unresolved?

Exact threshold and probability claims remain update-sensitive even when several articles repeat them. Server behavior and game patches can make observations diverge. This wiki keeps ranges and source labels visible until current evidence supports a narrower answer. For spending or time-heavy decisions, confirm the live interface before acting.

When submitting new evidence, identify which unresolved claim it addresses and include the observation date and visible conditions. That lets an editor narrow one uncertainty without treating a single result as proof of every mechanic in the update.
